CashIn

Android app Team project

What it is

CashIn is a native Android app designed to help users understand cash flow, manage budgets, and set savings goals, with their data synced to the cloud across devices.

My role

Built with a four-person team on a shared repository for CS4520/5520 Android Development at Northeastern. I developed the authentication feature branch:

  • Welcome, Login, and a three-page register/onboarding flow
  • An AuthViewModel wiring up Firebase email/password authentication and Google Sign-In via Credential Manager
  • App navigation and the nav bar

Along the way I resolved cross-platform integration issues, including Firebase SHA-1 fingerprint configuration and emulator-based testing of Google Sign-In.

Key features

  • Custom spending categories and tracking
  • Progress indicators for savings goals
  • Sign in with email and password or with Google
  • Cloud-synced data across devices
  • Declarative interface built with Jetpack Compose
