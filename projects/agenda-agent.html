Agenda Agent

Full-stack web app Individual project

What it is

Agenda Agent is a full-stack meeting agenda generator that helps teams structure meetings, set follow-up actions, and keep agendas concise and easy to use.

How it works

At its core is a rule-based algorithm that allocates the available meeting time across topics by priority, so the agenda that comes out reflects what actually matters rather than an even split. Generated agendas can then be exported to PDF or emailed to attendees automatically.

Designed and built solo as the midterm project for CS5610 Web Development at Northeastern.

Key features

  • Agenda creation and progress tracking
  • Meeting notes with action item summaries
  • Accounts secured with local auth and token-based sessions
  • Agendas exported to PDF
  • Agendas delivered by email
  • Accessible layout for busy teams

Try it

The app is deployed and open to try — it opens on the sign-in screen, so create an account to generate an agenda. It runs on free hosting, so the first load after a quiet period can take up to a minute to wake up.
